## Key Features
* **Responsive Layout:** Displays cleanly across desktop, tablet, and mobile screens.
* **Project Showcase:** Dedicated page to explore individual project details (`portfolio-details.html`).
* **Service Overview:** Clear layout highlighting offered technical services (`service-details.html`).
* **Working Contact Form:** Integrated PHP form handler to process visitor inquiries (`forms/contact.php`).
* **Custom Error Handling:** Dedicated custom error page for broken links (`404.html`).

## Tech Stack
* **Frontend:** HTML5, CSS3, SCSS, JavaScript
* **Backend (Contact Form):** PHP (`forms/contact.php`)
* **Libraries:** Vendor Libraries (`assets/vendor/`)

## Project Structure
* `assets/` — Stylesheets (CSS, SCSS), JavaScript files, images (`img/`), and third-party libraries (`vendor/`)
* `forms/` — Backend script for handling contact form submissions (`contact.php`)
* `index.html` — Main landing page of the portfolio
* `portfolio-details.html` — Detailed view page for individual projects
* `service-details.html` — Detailed overview page for offered services
* `starter-page.html` — Base template for creating new pages
* `privacy.html` & `terms.html` — Privacy policy and terms of service pages
* `404.html` — Custom Page Not Found error page

## How to Run

### 1. On a Computer (Directly in a Browser)
1. Download the project by clicking **Download ZIP** or using `git clone`.
2. Open the project folder and double-click **`index.html`** to open it directly in your browser.

### 2. To Enable the Contact Form (Using XAMPP)
1. Move the project folder into your `C:\xampp\htdocs\` directory.
2. Open the **XAMPP Control Panel** and click **Start** next to **Apache**.
3. Open your browser and navigate to `http://localhost/your-folder-name/`.

### 3. In GitHub Codespaces (Directly in the Browser)
1. On the GitHub repository, click **Code > Codespaces > Create codespace on main**.
2. In VS Code, use the **Live Server** extension and click **Go Live** (Port `5500`), or run `php -S 0.0.0.0:8000` in the terminal.
